# Rule changes v3 (apply on top of prototype_rules.md + prototype_rules_v2_changes.md)

All v1 and v2 rules still apply except where changed below. Approved by the designer after simulation round 2.

## 1. Guardian gets an attack
- Guardian role pool: Fortify is removed and replaced by **Shield Bash**: Minor, range 1, physical attack 1d8, on hit push the target 1 tile directly away from the user (if the destination is blocked or off-board, no push).
- Tidewall test loadout becomes: Taunt, Shield Bash, Counter, Pincer Guard (Shield Bash replaces Shield Wall in the loadout; Shield Wall stays in the role pool).
- Heavy units resist push as before (Tidewall cannot be pushed by Shield Bash of another unit only if a rule says so; currently no such rule).

## 2. Tamer protection (replaces the v2 protection rule)
- While at least one allied monster (alive) is adjacent to the Tamer, every enemy attack roll against the Tamer has DISADVANTAGE, at any range. This replaces the v2 rule that blocked targeting from distance >= 2 and the Burst exclusion.
- It is a normal disadvantage source, so it cancels with any advantage source per the standard rule.
- Save-based skills (Taunt, Hex, Distract) are not attack rolls and are not affected.

## 3. Defend
- Defend gives Guard and Ward +2 (was +4). Duration unchanged.

Everything else from v2 (Tamer HP 25 + 4 x (Lv - 1), Tamer basic 1d6, Command +1 move and no Command on a side's first turn, Flying ignores LOS only as attacker, Tidewall Move 3 and Guard +2, Counter Minor, Long Shot range 4, monster HP +3 x stars, official rulings) is unchanged.
