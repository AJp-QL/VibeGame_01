# docs/decisions/

บันทึกการตัดสินใจด้านออกแบบและเทคนิค (decision log) ที่ยืนยันแล้ว

## เก็บอะไร
- decision-log.md : ตารางการตัดสินใจทั้งหมดเรียงตามวันที่

## อ้างอิง PRD
- ทุก section, โดยเฉพาะ Risks/open questions เมื่อปิดประเด็นได้

## แนวทาง/กฎการตั้งชื่อ
- รูปแบบตาราง: วันที่ | การตัดสินใจ | ที่เลือก | ทางเลือกอื่น | แหล่งที่มา
- วันที่ใช้ YYYY-MM-DD, หนึ่งแถวต่อหนึ่งการตัดสินใจ, เพิ่มแถวใหม่ท้ายตาราง
- ถ้าเปลี่ยนใจ ห้ามลบแถวเดิม ให้เพิ่มแถวใหม่และระบุว่าแทนที่แถวไหน
- แหล่งที่มา เช่น PRD, sim รอบ N, playtest เกม N, rules vN
