# docs/prd/

ที่เก็บ PRD ฉบับ export (snapshot) ของ Monster Tactics RPG

## เก็บอะไร
- ไฟล์ export ของ PRD จาก Claude Docs (ต้นฉบับตัวจริงอยู่ที่ Claude Docs)
- snapshot เก่าเมื่อ PRD มีการแก้ใหญ่

## อ้างอิง PRD
- ทั้งเอกสาร: Overview, Goals, Personas, Core game loop, F1-F7, Content/progression/economy, Technical requirements, MVP roadmap, Prototype kit, Risks/open questions
- ต้นฉบับ: https://claude.ai/code/artifact/e9faa4d2-0774-4340-a591-ae0e4549504d

## แนวทาง/กฎการตั้งชื่อ
- ตั้งชื่อ prd_<YYYY-MM-DD>.md ตามวันที่ export
- ห้ามแก้ไฟล์ export ตรงนี้ ให้แก้ที่ Claude Docs แล้ว export ใหม่

## สถานะ
- ยังว่าง, รอ export จาก Claude Docs มาวาง
