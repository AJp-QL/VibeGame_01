# docs/

เอกสารทั้งหมดของโปรเจกต์ ทั้ง PRD, design, การตัดสินใจ และผล playtest

## เก็บอะไร
- prd/ : export ของ PRD จาก Claude Docs
- design/ : เอกสารออกแบบเชิงลึกที่แตกออกมาจาก PRD
- decisions/ : decision log
- playtest/ : บันทึกการเล่นทดสอบ paper prototype และเครื่องมือทอยเต๋า

## อ้างอิง PRD

- เอกสารเป็น Markdown (.md), ชื่อไฟล์ใช้ตัวพิมพ์เล็กคั่นด้วย - หรือ _
- ภาษาไทยเป็นหลัก ศัพท์เทคนิคใช้ภาษาอังกฤษได้
