# art/sprites/monsters/palette/

ชุดสีสำหรับ recolor sprite

## เก็บอะไร
- ไฟล์ PNG ของ layer palette
- เก็บเป็นภาพ swatch หรือไฟล์ข้อมูลสีที่อ้างอิงได้ ต้องกำหนดรูปแบบก่อนเฟส 1

## อ้างอิง PRD
- F7 Monster design (sprite composition 6 layers)
- Technical requirements (pixel art 32x32)

## แนวทาง/กฎการตั้งชื่อ
- <species>_palette_<variant>.png เช่น fangrel_palette_01.png
- ไฟล์ PNG ขนาด 32x32 ต่อเฟรม, scale ด้วย nearest-neighbor เท่านั้น (ห้าม smoothing)
