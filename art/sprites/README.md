# art/sprites/

sprite ของตัวละคร แยกมอนสเตอร์กับ Tamer

## เก็บอะไร
- monsters/ : ชิ้นส่วน layer ของมอนสเตอร์
- tamer/ : sprite ของ Tamer

## อ้างอิง PRD
- F5 Tamer, F7 Monster design, Technical requirements

## แนวทาง/กฎการตั้งชื่อ
- ไฟล์ PNG ขนาด 32x32 ต่อเฟรม, scale ด้วย nearest-neighbor เท่านั้น (ห้าม smoothing)
- รูปแบบชื่อ <subject>_<layer>_<variant>.png

## สถานะ
- ยังว่าง
