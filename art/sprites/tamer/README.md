# art/sprites/tamer/

sprite ของ Tamer (ตัวผู้เล่น) แยกตาม class

## เก็บอะไร
- sprite ของ 4 class: Beastwarden, Rune Caller, Mender, Trickster

## อ้างอิง PRD
- F5 Tamer, Technical requirements (pixel art 32x32)

## แนวทาง/กฎการตั้งชื่อ
- tamer_<class>_<variant>.png เช่น tamer_beastwarden_01.png, tamer_rune_caller_01.png
- ไฟล์ PNG ขนาด 32x32 ต่อเฟรม, scale ด้วย nearest-neighbor เท่านั้น (ห้าม smoothing)
